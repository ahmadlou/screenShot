Why can’t this page set the shortcut for me?

Chrome does not expose an API that lets an extension change its own keyboard shortcut. chrome.commands can only read the current binding (chrome.commands.getAll()) and listen for it (chrome.commands.onCommand) — there is no update() or set() method. Rebinding is intentionally reserved for the user, so an extension can never silently steal a keyboard combination.

This page shows the binding that is really active (read live from Chrome, not from our own settings), validates a combination before you commit to it, and then takes you to the one page where Chrome lets you apply it.
