Why can’t this page set the shortcut for me?

Chrome does not expose an API that lets an extension change its own keyboard shortcut. chrome.commands can only read the current binding and listen for it; applying a change is intentionally reserved for the user.

This page shows the shortcut that is actually active, validates a combination, and then takes you to Chrome’s shortcut page to apply it.

Press a combination such as Ctrl+Shift+S to check it before applying it in Chrome.
